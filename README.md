# Babka's Pizza Company

Mobile wood-fired catering site for Babka's Pizza Company. Come taste the difference.

Live site: GitHub Pages URL will appear here after the first deploy.

## Local preview

Open `index.html` in a browser, or from this folder run:

```bash
python3 -m http.server 8080
```

Then visit http://localhost:8080

## Booking form

The booking form currently confirms on the page so people can try the flow. To receive real requests, connect the form to [Formspree](https://formspree.io) or [Formsubmit](https://formsubmit.co) and point it at the shop email.
